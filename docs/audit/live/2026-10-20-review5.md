  that the filing's own text does not print. Amounts are matched in crore, lakh, million, thousand or rupees; EPS to
  the paisa.

    the filing that read them, which is how Bajaj's first-reported figure counted as "its own".
  - The check runs only on a line whose current figure the text prints. If the text missed the table, the
    comparatives stay as they were.
  - It only takes figures away, never adds them, so the standing audit rule does not apply.
  - Measured on this review's 5 results cards (no AI): Bajaj's year-ago revenue is dropped; Gallantt and UltraTech are
    unchanged.

    EPS line is left alone because its current EPS is not readable either. Production reads such pages with OCR first.
  - Test: `test_the_results_table_drops_a_comparative_the_filing_does_not_print`.
